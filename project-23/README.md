```markdown
# WhatsApp Bot

Esse é um bot simples para WhatsApp que permite banir usuários com o comando `!ban`. Apenas administradores podem usar esse comando.

## Instalação

1. Clone este repositório.
2. Navegue até a pasta do projeto.
3. Execute `npm install` para instalar as dependências.
4. Faça login no WhatsApp escaneando o QR code que aparecerá no console.
5. Execute `npm start` para iniciar o bot.

## Comandos

- `!ban <número>`: Banir um usuário. Somente administradores podem usar.
```
